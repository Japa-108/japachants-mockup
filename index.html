Core principle✦ Two modes

How users read a chant

Every chant opens in one of two modes. The mode toggle sits at the top of the chant screen. The user's preferred default (study or chant) is remembered.

📘
Study mode
Learn the meaning. See Sanskrit + transliteration + a line-by-line translation + meaning. Scholarly, verse-by-verse.
✦
Chant mode
Actually chant along. One script only (user picks the language). Continuous scroll, very large text, no verse chrome, minimal distraction.
